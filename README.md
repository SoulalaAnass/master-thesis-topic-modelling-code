# Topic Modelling in German Medical Language — Code & Artefacts

Master's thesis · M.A. Data and Discourse · TU Darmstadt · Anass Soulala

German online doctor reviews are split into sentences, embedded with **GottBERT**,
grouped into topics with **BERTopic**, profiled with rule-based **linguistic
features**, and read closely with **spaCy dependency parses**. The goal is to show
how patients express *stance* (praise, complaint, hedging, recommendation) in
language — not to measure clinical quality.

This repository contains everything behind the thesis, in three folders:

| Folder | What's inside |
|--------|---------------|
| `code/`    | The analysis scripts, numbered in run order |
| `data/`    | The result tables (CSV) the thesis is built on |
| `figures/` | The exact figures shown in the thesis |

---

## `code/` — what each script does

Run them in order, **from the repository root** (e.g. `python code/step1_embed_sentences.py`).

| Script | What it does | Produces |
|--------|--------------|----------|
| `step1_embed_sentences.py` | Loads the dataset, splits reviews into sentences, embeds each with GottBERT | `data/sentences_data.csv`, `data/german_embeddings.npy` |
| `step2_model_topics.py` | Clusters the embeddings into topics (UMAP → HDBSCAN → c-TF-IDF) | `data/topic_info.csv`, `data/sentences_with_topics.csv`, `data/topic_representatives.csv` |
| `step3_extract_features.py` | Counts linguistic features per sentence (modal particles, hedging, evaluation, negation, connectives, intensifiers, temporal, medical) | `data/linguistic_features.csv`, `data/topic_linguistic_analysis.csv` |
| `step4_dependency_parses.py` | spaCy dependency parses of the representative sentences | `data/parse_tree_analysis.csv`, parse HTML in `figures/parse_html/` |
| `step5_make_chart_figures.py` | Draws the chart figures (topic sizes, coverage, feature heatmap, topic profiles) | `figures/fig4-1 … fig4-4` |
| `step6_make_parse_tree_figures.py` | Renders the clean dependency-parse tree figures | `figures/fig4-5 … fig5-2` |

## Reproducing the results

```bash
pip install -r requirements.txt
python -m spacy download de_core_news_sm
```

1. Download the dataset (below) and save it in the repo root as
   `german_doctor_reviews_stratified_sample.csv`.
2. Run `code/step1` … `code/step6` in order, from the repo root.

The CSVs in `data/` are already included, so every thesis table and chart can be
checked directly without re-running anything. Sampling and UMAP use a fixed seed
(`random_state=42`); the pinned versions in `requirements.txt` reproduce the
reported topic structure (42 topics, largest 532, 35.35 % coverage).

### Dataset

> *German language reviews of doctors by patients (2021)*, Michael C.
> https://data.world/mc51/german-language-reviews-of-doctors-by-patients

The data is **not** redistributed here. The numeric rating column follows the
German school-grade convention (1 = best … 6 = worst).

### Note on the linguistic features

Features are rule-based lexicon counts (as described in the thesis methodology).
They are descriptive approximations: evaluation terms are matched as substrings and
a few items (e.g. *aber*, *denn*) belong to more than one list. The topic model is
a discovery layer; the close reading of representative sentences carries the
linguistic argument.
